# Course folder: Intro to Leadership and Management for Dummies

Open `index.html` in Chrome, Edge, Safari or Firefox on a computer, tablet or phone. No internet or installation needed. Keep the `css`, `js` and `docs` folders next to `index.html`.

- 11 modules in 5 parts, each with a 5-question check-in quiz, plus a 30-question final assessment (80% to pass)
- `js/content.js` holds all module text and all quiz questions (edit here to update content)
- `css/style.css` holds the look and feel (mobile-first, light and dark mode)
- `docs/question-bank.md` lists every formative and summative question with answers
- To use in an LMS, upload the folder as a web package or host it on an intranet site; on a phone, host it on any web server and open the link
